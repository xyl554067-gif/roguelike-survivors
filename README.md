## 🕹️ 玩法

1. 主菜单选**角色**与**难度**，点开始
2. 击杀敌人掉落 💎 经验与 💛 金币；经验满即升级
3. **每次升级三选一**：新武器 / 武器升阶 / 被动叠加 /（满足条件时）武器进化
4. 每 **90 秒**一次敌潮包围；每 **90 秒**一名小 Boss（强度随时间抬升）
5. 活过 **30:00** 并击杀**深渊领主**即通关，本局金币结算入库
6. 用金币在**商店**购买永久强化，再挑战更高难度

## 🚀 本地运行

无需安装任何依赖，二选一：

```bash
# 方式 1：内置零依赖服务器（推荐）
node serve.js          # 打开 http://localhost:5173

# 方式 2：任意静态服务器
python -m http.server 8000
npx serve .
```

> 也可以直接双击 `index.html` 打开。但 `file://` 协议下 `localStorage` 行为因浏览器而异，**建议用本地服务器**以获得完整存档功能。

### 测试

```bash
npm test
```

包含四套无头测试：

- **`tools/htmlcheck.js`** —— HTML 结构校验：全部元素 ID、页签/面板配对、无残留旧引用
- **`tools/selftest.js`** —— 数据完整性（26 武器 / 18 被动 / 17 敌人 / 5 首领 / 20 成就 / 11 商店项 / 12 修正器 / 10 条进化配方合法性）、存档读写、商店加成、9 角色模拟对局、长局压力、进化流程、成就解锁、种子随机可复现、挑战修正器生效、手柄输入
- **`tools/uitest.js`** —— DOM 桩驱动完整 UI 流程：6 页签切换、每日/随机挑战、挑战开局与成绩入库、商店渲染、开局、升级选卡、暂停、结算、返回菜单
- **`tools/leveluptest.js`** —— 升级卡片专项回归：可见性、连续多帧不闪变、DOM 不重复重建、可点击生效、连续升级、跳过/重掷/键盘选卡

> 另有 `tools/_verify_bug.js` 用于验证测试自身有效性：它会逐个还原历史 bug，确认断言确实能捕获，防止「测试全绿但 bug 还在」。

## 📅 每日挑战

挑战页签每天生成一套固定词条（种子来自日期），全球玩家同一天面对完全相同的怪物序列，方便比较成绩。

**修正器一览**（每日抽 3 个，随机挑战可重摇）：

| 修正器 | 效果 |
|--------|------|
| 🐛 虫潮 | 敌人 +50%，经验 +20% |
| 💥 玻璃大炮 | 伤害 +60%，受伤 +50% |
| 🛡️ 铁人 | 生命 +50%，移速 -15% |
| 🔥 狂暴 | 攻速 +35%，敌人更快 |
| 💰 赏金 | 金币 ×2，敌人血量 +30% |
| 🌫️ 黑雾 | 视野缩小，掉落 +80% |
| 💨 疾风 | 移速 +25%，冲刺冷却 -50% |
| 🍂 荒芜 | 治疗 -60%，经验 +40% |
| 👑 精英潮 | 精英更多，金币 +50% |
| ⚔️ 背水一战 | 无法复活，全属性 +20% |
| 🐌 迟滞 | 敌人 -25% 移速，攻速 -15% |
| 🎁 寻宝 | 宝箱翻倍，敌人血量 +25% |

连续游玩会累计 🔥 连续天数。

## 🏗️ 设计要点

- **模块化但零构建**：五个 `<script>` 顺序加载，共享 `window.DSData / DSSave / DSGame / DSUI`，无需打包器
- **性能守卫**：敌人上限 380、弹幕 700、粒子 700；敌人分离检测按索引抽样（每 4 个取 1）；关闭粒子可显著提升帧率
- **难度动态缩放**：敌人血量/伤害随时间抬升；**Boss 血量按玩家实时 DPS 估算缩放**，保证 20~40 秒可击杀，避免「打不动的血墙」
- **经济闭环**：局内金币 → 结算入库 → 商店永久强化 → 挑战更高难度
- **成就驱动解锁**：击杀 500 解锁亡术、存活 10 分钟解锁守誓者、通关解锁剑圣

## ⚠️ 已知限制

- 无音效采样文件，全部音效由 WebAudio 实时合成（音色偏 8-bit）
- 存档为 `localStorage` 单机存储，换设备需手动导出/导入
- 移动端在低配设备上建议关闭粒子特效
- 暂不支持手柄与外接键盘自定义映射
