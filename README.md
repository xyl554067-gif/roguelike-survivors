# 🎮 夜刃求生 · Roguelike Survivors

> 一款**纯前端 Canvas 实现**的**肉鸽割草生存小游戏**，30+ 可叠加武器与被动，无依赖开箱即玩！

![Screenshot](docs/screenshots/screenshot.png)

## ✨ 特性

- **肉鸽 + 割草双修**：每局随机升级，选择不同武器组合构建 Build
- **吸血鬼幸存者风格**：自动攻击 / 成长型爽感 / 尸山血海的压迫
- **6 分钟一局**（标准难度），最长存活 30 分钟挑战终局 Boss
- **7 大初始角色**：剑士、枪手、咒师、武僧、游侠、亡术……
- **12 种独特武器**：鞭影、飞刀、火球、罡气、飞斧、灵弹、雷链、回旋镖、圣典、冰爆、炮轰、锯齿轮……
- **16 个被动技能**：力量、体魄、铁甲、疾行、急速、疆域、贪婪、持久、增幅、迅捷、致命、生机、不灭、点金、智慧、破甲……
- **多关卡敌人类型**：史莱姆、蝙蝠、骷髅、幽灵、巨兽、喷吐者、虫群、冲锋者、邪符、重甲兵、奶妈……
- **Boss 战系统**：巨魔·戈尔林 → 巫妖·奈克罗 → 双生子·影与焰 → 深渊领主·卡尔
- **原生 Canvas + WebAudio 合成音效**：零第三方库，极致轻量
- **响应式设计**：桌面/平板/手机端自适应，支持触屏操作

## 🕹️ 操作

| 按键 | 功能 |
|------|------|
| `W`/`A`/`S`/`D` 或 `↑↓←→` | 移动角色 |
| 屏幕拖动 | 移动端移动 |
| `P` 或 `Esc` | 暂停游戏 |
| `M` | 静音开关 |

## 🚀 玩法

1. 从菜单中选择角色与难度
2. 击杀敌人掉落经验宝石（蓝色）与金币（黄色）
3. 拾取宝石后自动升级，**每次升级三选一**强化（新武器 / 现有武器升阶 / 被动叠加）
4. 持续生存，每 90 秒敌潮包围，每 60 秒小 Boss 降临
5. **击败深渊领主即可通关！**

### 💡 Build 技巧

- **近战流**：鞭影 + 罡气 + 疆域 + 力量 + 急速  
  *宽幅挥击 + 光环磨血 + 强力击退*
- **远程弹幕流**：飞刀 + 灵弹 + 增幅 + 急速 + 迅捷  
  *多弹齐发，满屏索敌*
- **AOE 法师流**：火球 + 圣典 + 疆域 + 力量 + 疾行  
  *爆炸范围覆盖全场，经书环绕输出*
- **暴击狂徒**：飞斧 + 飞刀 + 致命 + 力量 + 破灭  
  *高伤暴击秒杀精英与 Boss*

## 🔧 开发

- **无需构建工具**，直接浏览器打开 `index.html`
- **本地测试**：
  ```bash
  python -m http.server 8000
  ```
  访问 `http://localhost:8000`
- **GitHub Pages 部署**：通过仓库的 Settings → Pages 开启

## ⚠️ 注意

- 本作无存档（暂不推荐多次游玩策略性 Build），建议以体验流程为主
- 移动端性能受设备限制，低配设备建议调小窗口或降低特效复杂度
- 如遇卡顿，可尝试关闭音效（`M`）以提升帧率
